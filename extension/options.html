Tweet FactChecker

推文事实核查 · 本地运行，密钥不出浏览器

Anthropic API Key

本扩展直接用你自己的 Anthropic 账户调用 Claude。密钥只保存在这台设备上， 仅发往 api.anthropic.com，不经过任何第三方服务器。

还没有密钥？到 Anthropic 控制台 创建，并确保账户中有可用额度。

关于花费

每次核查会调用一次 Haiku（抽取断言）、以及对每条断言各两次 Sonnet（联网搜证 + 复核）。费用按 Anthropic 官方价目从你的账户扣除，典型单次核查约 $0.10–0.35，取决于推文里断言的条数。扩展本身不收费， 开发者也不经手你的任何费用。

隐私

你点击核查的推文文本会发往 Anthropic 用于核查，联网搜证会将断言内容作为搜索词。 除此之外扩展不收集、不上传、不存储任何数据；没有分析埋点，没有远程服务器。 详见 隐私政策。
