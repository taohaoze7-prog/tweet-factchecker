### 简短说明（上限 132 字符）

```
在 X/Twitter 上一键核查推文里的事实性断言：联网搜证、独立复核，给出带来源链接的结论。用你自己的 Anthropic API Key 运行。
```

### 详细说明

```
Tweet FactChecker 在 X/Twitter 的每条推文旁加一个「核查」按钮。点一下，它会：

1. 抽取断言 —— 把推文拆成一条条可独立验证的事实性陈述，跳过观点、玩笑和情绪表达。
2. 联网搜证 —— 为每条断言检索权威来源，交叉验证，避免单一信源。
3. 独立复核 —— 第二个模型以「魔鬼代言人」身份审查初判，专挑证据缺口、来源偏见与逻辑跳步。
4. 给出结论 —— 属实 / 基本属实 / 真假参半 / 大体不实 / 不实 / 无法核实，附可信度与每条证据的原始链接。

请预留 2–4 分钟

一次核查通常要 2 到 4 分钟。这不是卡住了：每条断言都要真的联网检索、交叉验证，再由第二个模型独立复核一遍。卡片会实时显示进度和秒表，断言逐条填入，你可以先去做别的事，回来看结果。

想要秒回的话，本扩展不适合你——那种速度做不到真正的搜证。

设计原则

· 可追溯优先。每条证据都必须带可点开的来源链接；点不开的「来源」会被直接丢弃，而不是当成证据展示。
· 不确定就说不确定。证据不足时明确标为「无法核实」，绝不硬凑结论。多条断言中若只核实了一部分，结论里会明写覆盖率，不让整体判定掩盖未核实的部分。
· 无服务器。扩展没有后端。你的密钥只存在这台设备上，核查请求直接发往 Anthropic，不经过开发者的任何服务器——开发者看不到你核查了什么。

使用前提

本扩展用你自己的 Anthropic API Key 运行（在 console.anthropic.com 免费创建）。
费用由 Anthropic 按官方价目从你的账户扣除，典型单次核查约 $0.10–0.35，取决于推文里断言的条数。扩展本身免费，开发者不抽成。

⚠️ 关于局限

自动核查会出错。模型可能误读断言、检索到不可靠来源，或对时效性极强的事件给出过时结论。请把结论当作「带来源的调查起点」，而不是最终裁决——每条证据的链接都可点开，请自行判断。
```

## 二、权限用途说明（Console 逐项填写）

审核员会逐条比对权限与实际用途。以下与代码实现一一对应：

| 权限 | 填写内容 |
|------|----------|
| `storage` | 在本机保存用户的 Anthropic API Key 及核查有用性标记。不同步、不上传。 |
| `host_permissions: https://api.anthropic.com/*` | 从后台脚本直接调用 Anthropic API 完成核查。必须由后台发起：X/Twitter 的 CSP 会拦截页面内脚本的跨域请求。 |
| 内容脚本 `x.com` / `twitter.com` | 在推文操作栏注入「核查」按钮，并在推文下方渲染结果卡片。 |

**远程代码**：选「不使用」。所有逻辑随扩展包一起分发，不动态加载脚本。

## 三、数据用途声明（Data Safety）

| 问题 | 勾选 |
|------|------|
| 收集个人身份信息 | 否 |
| 收集健康信息 | 否 |
| 收集财务信息 | 否 |
| 收集认证信息 | **是** —— API Key 存于本机，仅用于向 Anthropic 认证；不传输给开发者 |
| 收集个人通信内容 | **是** —— 用户主动点击核查的推文文本会发往 Anthropic 处理；不传输给开发者、不存储 |
| 收集位置 / 浏览记录 / 用户活动 | 否 |
| 出售或转让给第三方 | 否 |
| 用于与核心功能无关的用途 | 否 |
| 用于判定信用状况 | 否 |

> 认证信息与通信内容两项**必须勾「是」**。虽然数据不流向开发者，但确实离开了扩展（发往 Anthropic）。谎报是拒审与下架的常见原因，如实填写并在隐私政策中说明流向，反而更容易过审。

### 建议的 5 张截图

1. **核查按钮** —— 推文操作栏里的「✓ 核查」，展示注入形态
2. **核查中** —— 流式骨架 + 实时秒表，说明是渐进式的
3. **结论卡片** —— 环形可信度仪表 + 大裁决（挑一条判定为「不实」的，视觉冲击最强）
4. **证据展开** —— 逐条来源链接与摘录，突出「可追溯」这个卖点
5. **设置页** —— 说明 BYOK 与「密钥不出本机」

> 截图里务必**打码或避开真实用户的头像与 handle**——用官方账号的公开推文，或自建测试推文。截图中出现可识别的第三方个人信息是常见的拒审理由。
