Tweet FactChecker 隐私政策

最后更新：2026 年 8 月 25 日

核心事实：本扩展没有服务器。 开发者不运营任何后端服务，不接收、不存储、不传输你的任何数据。 扩展完全在你的浏览器内运行，唯一的对外网络请求是直接发往 api.anthropic.com——用你自己的 Anthropic 账户。

一、我们收集什么

不收集任何数据。本扩展没有分析埋点、没有崩溃上报、没有用户标识，也没有可供上传数据的服务器。

二、数据在本机如何存储

数据 存储位置 用途 如何删除
Anthropic API Key 本机 chrome.storage.local 调用 Claude 完成核查 设置页「清除」，或卸载扩展
核查有用性标记（👍/👎） 本机 chrome.storage.local（最多 200 条） 供你自己参考；不会自动上传 卸载扩展即清除

两项均使用 storage.local 而非 storage.sync， 因此不会同步到你的其他设备，也不经过 Google 的服务器。

三、数据发往何处

当你主动点击某条推文的「核查」按钮时，以下内容会发送给 Anthropic：

  • 该条推文的文本内容
  • 从中抽取出的事实性断言（会作为联网搜索的检索词）
  • 你的 API Key（作为身份凭证）

不点击核查按钮时，不发送任何内容——扩展不会在后台读取或上传你浏览的推文。 这些数据的处理受 Anthropic 隐私政策 约束，与开发者无关；开发者无法看到其中任何内容。

四、费用

扩展本身免费。核查产生的模型调用费用由 Anthropic 直接从你的账户扣除， 开发者不经手、不抽成、也无法查看你的用量。

五、权限说明

权限 为什么需要
storage 在本机保存你的 API Key 与反馈标记
api.anthropic.com 主机权限 从扩展后台直接调用 Claude。必须由后台发起：X/Twitter 的内容安全策略（CSP） 会拦截页面内脚本的跨域请求
在 x.com / twitter.com 上运行内容脚本 在推文旁注入「核查」按钮，并在推文下方渲染核查结果卡片

六、第三方

除 Anthropic 外，本扩展不与任何第三方通信，不含广告、追踪器或分析 SDK。 核查过程中的联网搜索由 Anthropic 服务端执行，不经过开发者。

七、儿童

本扩展面向成年用户，不针对 13 岁以下儿童，也不会有意收集其信息。

八、政策变更

政策若有实质变更，将更新本页顶部的日期，并在扩展的版本更新说明中注明。
